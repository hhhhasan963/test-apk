# دوامي المدرسي — Android Native

تطبيق Android أصلي مبني بـ **Kotlin + Jetpack Compose**. يعمل محليًا بالكامل من دون إنترنت أو خادم أو حساب، ولا يحتوي على WebView أو PWA.

## ما الذي يعمل؟

- اختيار طالب/مدرس مرة واحدة وحفظ الاختيار محليًا.
- جدول الطالب الخاص، أو جدول المادة للمدرس مع دمج الشعب التي لها المادة نفسها في الحصة نفسها.
- عرض الحصة الحالية والقادمة، الاستراحة، انتهاء الدوام، وعدّاد يتحدث كل ثانية.
- الجداول اليومية والكاملة، ودعم الجمعة والسبت والعطل الاستثنائية.
- ملفات JSON خارجية قابلة للتحرير ومسارها:
  `Internal Storage/SchoolSchedule/data/`
- زر لإعادة تحميل الملفات واستعادة النسخ الافتراضية عند وجود خطأ.
- إشعارات مجدولة عبر `AlarmManager` قبل الحصة/عند البدء/عند النهاية؛ تعاد جدولتها بعد إعادة التشغيل أو تغيير الوقت.
- RTL وعربية كاملة.

## ملفات البيانات

عند التشغيل الأول، ينسخ التطبيق هذه الملفات إلى التخزين الداخلي العام:

- `SchoolSchedule/data/schedule.json`
- `SchoolSchedule/data/periods.json`
- `SchoolSchedule/data/holidays.json`

تعديل `periods.json` يدعم أي عدد من الحصص؛ التطبيق يرتب الحصص حسب `start` ولا يفترض ست حصص. في `schedule.json` تمثل `-` عدم وجود حصة.

> **أول تشغيل:** يطلب التطبيق إذن الوصول إلى الملفات حتى يستطيع المستخدم تعديل JSON باستخدام مدير الملفات، وإذن الإشعارات على Android 13+.

## البناء

يتطلب Android SDK API 35 وJDK 17+.

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew testDebugUnitTest assembleDebug
```

ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات الإشعارات

- تستخدم الإشعارات `AlarmManager` و`BroadcastReceiver`، لا مؤقتًا داخل الشاشة؛ لذلك لا تعتمد على بقاء التطبيق مفتوحًا.
- يعاد إنشاء جدول تنبيهات قادم لمدة 14 يومًا عند تغيير الإعدادات أو الملفات، وبعد إعادة تشغيل الجهاز أو تغيّر الوقت.
- على أجهزة Android الحديثة يمكن أن تتحكم إعدادات النظام في تنبيهات التطبيق والتنبيهات الدقيقة؛ أذونات التطبيق المعروضة في أول تشغيل مطلوبة لأفضل دقة.
